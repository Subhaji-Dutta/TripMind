# ✈️ TripMind — Multi-Agent AI Travel Planner

TripMind is an AI-powered travel planning application that uses multiple specialized agents to create a personalized trip plan.

The system combines real weather data, AI-generated travel options, user-selected preferences, AI-generated packing recommendations, itinerary generation, and deterministic budget calculation into one complete travel-planning workflow.

---

## 🌟 Features

- 🌦️ Real-time weather information using Open-Meteo
- 🚆 AI-generated outbound and return transport options
- 🏨 AI-generated accommodation recommendations
- 🍽️ AI-generated restaurant recommendations
- 🎯 Personalized activity and attraction recommendations
- 🧳 AI-generated packing list
- 🗓️ AI-generated day-by-day itinerary
- 💰 Deterministic trip budget calculation
- 🔄 Round-trip transport selection
- 💾 Persistent trip storage using JSON
- ⚡ FastAPI backend
- 🖥️ Streamlit frontend
- 🤖 Groq-powered AI agents
- 🧩 Modular multi-agent architecture

🤖 Agents
1. Orchestration Agent

The orchestration layer coordinates the travel-planning workflow.

It:

Creates the trip state
Calls the weather agent
Calls the transport agent
Calls the accommodation agent
Calls the restaurant agent
Passes collected information to the recommendation agent

The orchestrator itself does not use an LLM.

2. Weather Agent

Uses the Open-Meteo API to retrieve weather information.

It provides:

Temperature
Weather condition
Weather code
Rain probability
Daily forecast

No API key is required for Open-Meteo.

3. Transport Agent

Uses Groq to generate estimated transport options.

The agent generates:

3 outbound options
3 return options

Supported examples include:

Flight
Train
Bus

Transport prices and schedules generated by this agent are estimates and are not live booking availability.

4. Accommodation Agent

Uses Groq to generate accommodation options.

Each option contains:

Hotel/resort name
Location
Rating
Price per night
Total accommodation cost
Amenities
5. Restaurant Agent

Uses Groq to generate restaurant recommendations.

Each restaurant contains:

Name
Location
Cuisine
Price range
Estimated cost
6. Recommendation Agent

Combines information collected by the other agents and produces personalized recommendations.

It considers:

User interests
Weather
Transport options
Accommodation
Restaurants
Travel preferences

The agent produces:

Activities
Attractions
Restaurants
7. Packing Agent

Uses Groq to generate a personalized packing list.

It considers:

Weather
Rain probability
Selected activities
Selected attractions
Selected restaurants
Transport
Trip requirements
8. Itinerary Agent

Uses Groq to generate a day-by-day itinerary based on the user's selected options.

The itinerary includes:

Date
Weather
Morning activity
Afternoon attraction
Evening restaurant

The agent is designed to use the user's selected options rather than inventing unrelated selections.

9. Budget Calculator

The budget calculator is implemented using deterministic Python rather than an LLM.

It calculates:

Transport
+ Accommodation
+ Activities
+ Attractions
+ Restaurants
= Estimated Trip Cost

It also calculates:

Remaining Budget

and determines whether the estimated trip cost is within the user's budget.

🧠 Why Multiple Agents?

Trip planning contains several different types of tasks.

Instead of asking one LLM to perform everything, TripMind separates responsibilities:

Weather       → Weather Agent
Transport     → Transport Agent
Hotels        → Accommodation Agent
Restaurants   → Restaurant Agent
Recommendations → Recommendation Agent
Packing       → Packing Agent
Itinerary     → Itinerary Agent
Budget        → Python

This makes the system:

Modular
Easier to test
Easier to maintain
Easier to extend
More transparent

Deterministic tasks are intentionally handled with Python instead of an LLM.

⚙️ Installation
1. Clone the repository
git clone <your-repository-url>
cd tripmind
2. Create a virtual environment

Windows:

python -m venv .venv
3. Activate the environment
.venv\Scripts\activate
4. Install dependencies
pip install -r requirements.txt
🔐 Environment Variables

Create a .env file in the project root.

TRANSPORT_AGENT_KEY=your_transport_groq_key
ACCOMMODATION_AGENT_KEY=your_accommodation_groq_key
RESTAURANT_AGENT_KEY=your_restaurant_groq_key
RECOMMENDATION_AGENT_KEY=your_recommendation_groq_key
PACKING_AGENT_KEY=your_packing_groq_key
ITINERARY_AGENT_KEY=your_itinerary_groq_key

Never commit your .env file to Git.

Make sure .gitignore contains:

.env
.venv/
__pycache__/
.pytest_cache/
▶️ Running the Application

TripMind uses two processes.

Terminal 1 — Start FastAPI

From the project root:

uvicorn backend.main:app --reload

The backend will run at:

http://127.0.0.1:8000

FastAPI documentation:

http://127.0.0.1:8000/docs
Terminal 2 — Start Streamlit

Activate the virtual environment and run:

streamlit run frontend/app.py

Streamlit will provide the local application URL.

🔒 Security

API keys should always be stored in environment variables.

Do not:

Hard-code API keys
Commit .env
Share API keys publicly
Put API keys in frontend code

The Streamlit frontend communicates with the FastAPI backend, while API credentials remain on the backend.

⚠️ Important Limitations
Transport

Transport options are AI-generated estimates.

They do not represent:

Live ticket availability
Live fares
Confirmed schedules
Actual bookings
Accommodation

Accommodation recommendations are AI-generated suggestions and are not live hotel availability.

Restaurants

Restaurant recommendations are AI-generated and should be independently verified before booking.

Budget

The budget is an estimated calculation based on the generated/selected options.

📌 Project Goal

TripMind demonstrates how a multi-agent AI system can combine specialized AI agents, deterministic Python logic, external APIs, and a user-facing application to solve a real-world planning problem.

The project focuses on modularity, orchestration, validation, and practical AI application design rather than using an LLM for every task.
